# 调研简报

## 做法
1. 把问题拆成 2–4 个要查证的子问题 (谁 / 多少 / 什么时候 / 为什么)。
2. 每个子问题用 web_search 搜, 关键说法至少找两个独立来源互证; 数字优先找原始出处 (官方公告、财报、统计局、论文), 用 open_url 读原文核对。
3. 来源互相矛盾时, 两种说法都保留, 注明各自出处和时间, 不要自己挑一个当事实。
4. 查不到的就写查不到, 不要补编。
5. 只引用真正支撑结论的来源; 搜索结果里和问题无关的网页 (导航站、娱乐新闻等) 不要列进来源。

## 交付格式
开头直接写结论, 不要写「根据搜索结果, 我来整理一下」这类过渡句。
- **一句话结论** (直接回答用户的问题)
- **关键事实** 3–6 条, 每条末尾标 [序号]
- **分歧与不确定性** (没有就省略这一节)
- **来源**: [序号] 标题 — 链接

篇幅: 默认 400–800 字; 用户要"详细"再展开, 要"简单说"就只给结论和 3 条事实。
